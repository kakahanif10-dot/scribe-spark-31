# AI Workspace Rebuild

use for projec https://github.com/kakahanif10-dot/ai-landing-page-rebuild.git

The repository is publicly accessible (no auth needed). Clone it and rebuild the app to match it as closely as possible: same structure, routes (/, /login, /workspace, /api/chat, /api/generate), components, styling, and assets. It is a TanStack Start + React 19 + Tailwind 4 project — a landing page for "SUPERINTELLIGENS — Build software with AI" with landing components (site-header, hero, showcase, features, how-it-works, pricing-cta, site-footer), an auth form, and a workspace with chat panel, phone simulator, and preview panels.

This project was built with [Lovable](https://lovable.dev).
